# Glossary (kid language)

| Word | Meaning |
|---|---|
| **argument** | A value you give to a function, like the `200` in `ellipse(200, ...)` |
| **array** | A numbered row of boxes under one name (`x[0]`, `x[1]`, ...) |
| **boolean** | A variable that is either `true` or `false` |
| **bug** | A mistake in a program. Finding bugs is a skill. |
| **call (a function)** | Run a function by name: `drawHouse(10, 20);` |
| **canvas** | The window you draw on |
| **class** | A blueprint for making objects |
| **comment** | A note for humans after `//`; the computer ignores it |
| **condition** | A yes/no question inside an `if` |
| **console** | The black area under the code where `println` prints |
| **coordinate** | A position on the canvas: (x, y) |
| **debug** | Find and fix bugs |
| **declare** | Create a variable: `int x = 5;` |
| **float** | A number with decimals |
| **frame** | One picture in an animation |
| **function** | A named recipe you can run many times |
| **index** | The number of a box in an array (starts at 0) |
| **int** | A whole number |
| **iteration** | One round of a loop |
| **loop** | Code that repeats |
| **method** | A function that belongs to an object |
| **object** | One thing built from a class |
| **parameter** | The ingredient name inside a function definition |
| **pixel** | One dot on the screen |
| **return** | Hand an answer back from a function |
| **RGB** | Red, Green, Blue: three dials from 0 to 255 |
| **state** | Which "screen" or mode a program is in (title, playing, game over) |
| **statement** | One instruction, ending in `;` |
| **variable** | A labelled box that holds a value |
