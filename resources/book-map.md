# Book map

Chapter titles below were read from each book's table of contents. Only the Noble Lesson 3.1 section and a few passages were read in depth. **Read the chapter yourself before teaching from it.**

## Which book for which job

| Book | Style | Best used for |
|---|---|---|
| **Noble, *Programming Media Art Using Processing*** | Short numbered *lessons*, each with a project; figures show the code | The closest match to this course's lesson-by-lesson flow (Modules 1-10) |
| **Meyer, *Programming 101*** | University intro; each chapter builds a complete project; "Things to Look Up", "How to Make This Your Own" | Teacher background; projects beyond games (images, files, video, 3D) |
| **Nyhoff, *Processing: An Introduction to Programming*** | Textbook; every concept has text examples *and* a graphical example; summaries and exercises | Precise explanations; exercise banks; analogies for `if`, functions, arrays |
| **Cermak-Sassenrath, *Intro to Game Programming using Processing*** | Short numbered chapters, aimed at designers and non-programmers | Modules 3-10, especially game mechanics |
| ***Processing Creative Coding and Generative Art*** | Project-based generative art | Inspiration; stretch projects after Module 8 |
| ***Processing 2 Creative Programming Cookbook*** | Recipes (note: Processing 2, so some code is dated) | Ideas: 2D/3D drawing, exporting, audio, video |
| ***The SparkFun Guide to Processing*** | Physical computing (Arduino) | An optional hardware extension at the end |
| **McCarthy, *Getting Started with p5.js*** | Intro for Processing users | Module 11 |
| **Arslan, *Coding for Visual Learners*** | JavaScript through p5.js | Module 11 |
| ***Generative Design*** (p5.js) | Gallery of generative projects | Advanced learners / inspiration |
| ***Creating 3D Algorithmic Art with p5.js*** | 3D | Later 3D unit |
| **Creative Computing Curriculum + Learner Workbook** (Scratch, Harvard ScratchEd: <https://creativecomputing.gse.harvard.edu/guide/>) | Teaching units with *Debug It!*, critique groups, reflection | Facilitation practice; the session routine |

## Notes on teaching style, as found in the books
- **Noble** teaches variables in three explicit steps: declare, use in an argument, then make it change. This is mirrored in Modules 3 and 4.
- **Nyhoff** pairs each concept with a *graphical* example (thermometer, angle drawing, dice game) and uses a recipe analogy for `if`. He teaches `while` before `for`; this course reverses the order for faster visual feedback.
- **Cermak-Sassenrath** keeps chapters short and separates "relational expressions" from "conditionals", which is a good model if a group struggles with `&&` and `||`.
- **Meyer** ends each chapter with "How to Make This Your Own", which is the "Create" step of this course's Use-Modify-Create routine.
- The **Creative Computing** curriculum contributes the *Debug It!* activities, critique groups and reflection prompts.
